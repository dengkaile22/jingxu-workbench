# 四屏人物叠加性能与 GPU 处理优化

> 用户已要求直接优化并增加 GPU 加速，在当前任务内使用 subagent-driven-development 与 TDD 执行，不重复询问实施许可。

**目标：** 保留四屏、人物叠加、羽化与音轨语义，降低处理耗时和峰值资源占用，交付可安装更新。

**基线：** 本机 i5-13500H / Intel Iris Xe，1080×1440、30fps、2秒合成素材；QSV 编码。仅人物 3.57秒；仅四屏羽化12.15秒；四屏羽化+人物11.80秒；二者无羽化1.91秒。此为本机合成基线，不等同客户机器实测。客户失败退出码-12；相同随包FFmpeg的受控分配失败也返回-12，尚无客户完整日志。

**架构：** 先消除重复羽化计算，再增加经过设备探测的硬件解码路径，并保留软件解码和编码回退。CPU模式仍完全可用；无法在本机验证的GPU专用滤镜不直接设为默认。控制多源输入的线程/缓冲和跨片段扇出，减少长素材内存压力。

- [x] 用可重复的像素/同步测试约束视觉语义，避免以关闭羽化换取提速。
- [x] 优先改为一次生成并复用静态alpha渐变，或只处理单通道alpha；保持奇数格尺寸、横竖缝与交点正确。
- [x] 复用同源缩放，避免同一画面重复四次完整缩放。
- [x] 重新执行相同1080×1440四组基线并记录耗时。
