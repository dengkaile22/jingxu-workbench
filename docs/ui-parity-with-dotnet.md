# UI 与 .NET 版一致性对照

**目的：** 记录 Python 版（PySide6）与 .NET 版（WPF）界面的逐页对照结果。
**基准：** `src/JingXu.Workbench/Features/*/View.xaml` 的区块标题、控件文案与顺序。

> **关于「一模一样」的边界**：两版渲染栈不同（WPF vs Qt），控件外观、字体度量、
> 圆角与动画无法逐像素相同。本对照追求的是**结构一致、文案一致、分区一致、
> 交互一致**——即用户看到同样的区块、同样的措辞、按同样的顺序操作。
> 若要求像素级一致，需要放弃 Qt 改用与 .NET 同源的方案，不在本次范围内。

### 本轮顺带修掉的真实缺陷

| 缺陷 | 影响 | 修法 |
|------|------|------|
| **贴纸页透明度换算方向搞反** | 贴纸页套用了蒙版页的取反公式，「透明度 100%」把贴纸整个变没了 | 两页各自换算：贴纸 `opacity = 刻度/100`，蒙版 `opacity = 1 - 刻度/100` |
| 混剪页「自定义宽高」输入框没有接槽 | 改了宽高既不刷新描述也不通知预览 | 接上 `_refresh_aspect_state` |
| 数字输入框被自身行高截断 | 混剪页时长/旋转/强度等数字切掉一像素（内部行编辑 14px < 行高 15px） | 主题给 `QAbstractSpinBox` 加 `min-height: 24px` |
| 数值编辑不刷新白框 | 填完「源素材取景」数值后画布上的白框停在旧位置 | 写回后调 `_sync_canvases()` |
| **「自动上下偏移」措辞与 .NET 不一致** | 原写作「源上下偏移」，易与 .NET 的 `OffsetY`（蓝框位置 Y）混淆；两者取值域恰好都是 -1~1，但语义不同 | 按 .NET 原文改为「自动上下偏移」并补 tooltip；区块内四个数值标签也改为 X/Y/宽度/高度、按钮改为「重置为自动取景」 |
| **字幕 ASS 的 PlayRes 恒为 1080×1920** | `SubtitlePage.set_canvas_size` 此前**没有任何调用者**；画幅改成 720×1280 或自定义后，导出的 ASS 字号/边距基准是错的 | 由壳层的 `_sync_layer_canvas_aspect` 一并同步真实像素尺寸 |
| 蒙版表单透明度默认值与标签自相矛盾 | 标签写「0=不透明」却默认给 28 | 默认改为 72%（＝ .NET 的不透明度 0.28） |
| 高 DPI 布局用例存在顺序依赖 | 结论随执行顺序变化 | 用例内按 `__main__` 顺序显式注册字体 + 应用主题；并跳过纯图标 QLabel |
| **「尺寸」缩放整体缺失** | `LayerSpec.scale_percent` 被持久化但**没有任何消费者**，.NET 的 `Scale`（边界框内均匀缩放 1%–400%）在 Python 完全没生效，界面也没有入口 | 按 .NET `BuildRelativeScale` 逐行移植滤镜（>100% 中心裁回、<100% 透明 pad）；两页补「尺寸 %」控件（1–400，对齐 .NET 滑杆 0.01–4） |
| **「位置 X / 位置 Y」整体缺失** | .NET 用 `Bounds` + `OffsetX/OffsetY` 两套参数（后者整体挪框），Python 只有中心百分比，没有"框不动、只挪框"这一层 | 新增 `offset_x`/`offset_y` 字段，滤镜按 .NET 公式 `帧坐标 = 中心 + offset × 画面尺寸` 合成；蒙版页补「位置 X/Y」控件（-1~1）；旧项目缺键回落 0，落点不变 |
| **预览与渲染对不齐两处** | ① 预览的框不跟随 offset，会出现"画面动了预览不动"；② 预览把框夹回画布内，而滤镜图不夹（框可部分移出画布） | 预览按同一公式计算中心，并去掉画布内夹取，与渲染完全一致 |

## 本轮为对齐所做的修复

除文案与分区外，对齐过程中发现并修掉了几个真实缺陷：

| 缺陷 | 后果 |
|------|------|
| `Qt.Edge` 直接 `int()`（PySide6 6.x Flag 枚举） | 每次窗口左键按下抛异常、边缘拖拽缩放失效、崩溃日志被刷满 |
| 贴纸页与蒙版页共用同一参数表单 | 贴纸页显示羽化/蒙版适配/源上下偏移等蒙版专属项，无法理解 |
| 贴纸页没有素材库 | 只能靠「导入素材」逐条建轨道，缺少「库 → 轨道」流程 |
| 选品页单条添加默认强制「抖音」 | 粘贴快手链接被存成抖音账号（绕过自动识别） |
| 账号表窄窗口下挤掉列 | 「平台」列消失，账号串到链接列，看着像平台识别错 |
| 源素材取景只有后端没有入口 | 用户无法设置手工取景 |
