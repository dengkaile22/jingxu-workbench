## 制作说明（可复现）

全部脚本位于 `制作工具/`，路径均相对仓库根解析，仓库整体改名/搬家后仍可复现。

1. **演示素材**：`make_demo_graphics.py`（贴纸 / 蒙版形状）、`make_demo_media.py`（6 条商品短视频 + 2 条蒙版视频）、`make_demo_audio.py`（音频库 BGM）。
2. **界面截图**：`capture_ui.py` 以真实 Windows 平台 + `WA_DontShowOnScreen` 启动应用（1920×1080，注入 6 条素材 / 5 个对标账号 / 3 条筛选任务 / 4 个队列任务），逐页截屏并记录控件几何；`capture_scrolled.py` 补拍混剪页「编排」区域。
   > 注意：不能用 `QT_QPA_PLATFORM=offscreen`——该平台插件枚举不到系统字体，中文会全部渲染成方框。
   > 演示数据写入系统临时目录（`%TEMP%\jingxu-promo-appdata`），不污染真实用户数据。
   > 队列页截图前会清空字幕轨，否则「字幕时间轴超出素材时长」会让入队被拦下、截出空队列。
3. **场景合成**：`render_scenes.py` 用 Qt 把截图装进带阴影的卡片，叠加标题、编号标注，并生成闲鱼二维码与片尾落版（1920×1080）。
4. **配音**：`make_promo_30s.py` 用 edge-tts（zh-CN-XiaoxiaoNeural，+12% 语速）逐句合成，ffprobe 量每句时长。
5. **音乐**：`make_bgm.py` 用 numpy 合成 112 BPM 轻快电子音乐；30 秒版从中裁切并首尾淡入淡出。
6. **成片**：`make_promo_30s.py` 完成镜头时长分配（总长精确 30.000s）、zoompan 微推、0.4s 交叉转场、配音与 BGM 侧链闪避混合、ASS 字幕烧录。

```powershell
# 一次性重跑（Python 环境需 PySide6 / numpy / edge-tts / qrcode）
python 制作工具\make_demo_graphics.py
python 制作工具\make_demo_media.py
python 制作工具\make_demo_audio.py
python 制作工具\capture_ui.py          # 需 PySide6 + numpy
python 制作工具\capture_scrolled.py    # 需 PySide6 + numpy
python 制作工具\render_scenes.py       # 需 PySide6 + numpy + qrcode
python 制作工具\make_promo_30s.py      # 需 numpy + edge-tts
```

> **制作过程中同步修复的软件缺陷**：`core/jingxu/ui/shell_window.py` 的 `_refresh_gate_preview`
> 定义了后台任务函数但漏掉了线程启动行（同文件另外两处均有 `threading.Thread(...).start()`），
> 导致「导入素材后自动生成首帧预览」从未生效、取景井一直停留在加载状态。已补上启动行，
> 混剪页截图中的首帧预览即验证了修复效果。
