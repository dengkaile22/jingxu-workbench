# 炳恒快速混剪 - 安装与使用说明

本软件为完全离线的 Windows 桌面视频批量处理与混剪工具，支持随机/序号编排拼接、画幅自适应、滤镜贴纸、BGM 混音、多层蒙版叠加、离线字幕实验室（Whisper 转写 / OCR 定位擦除）与多任务恢复队列。

---

## 📦 安装包说明

* **文件名：** `炳恒快速混剪-win-x64.msi`
* **适用系统：** Windows 10 / Windows 11 (x64)
* **大小：** 约 191.9 MB
* **特性：**
  * **完全离线与自包含：** 已内置 .NET 10 运行时与 FFmpeg 等离线处理引擎，无需安装任何环境依赖。
  * **标准安装管理：** 安装到 `Program Files\炳恒快速混剪`，自动生成桌面和开始菜单快捷方式，支持系统控制面板卸载。
  * **安全隐私保证：** 不联网、不上云、本地执行全部音视频处理。

---

## 🚀 安装与启动

1. 双击运行 `炳恒快速混剪-win-x64.msi`。
2. 按照 Windows 安装向导提示完成安装。
3. 安装完成后，在**桌面**或**开始菜单**中点击「**炳恒快速混剪**」图标即可启动。

> ⚠️ **Windows SmartScreen 提示说明：**  
> 若 Windows 首次启动提示「未知发布者」或「已保护你的电脑」，请点击 **“更多信息”** → **“仍要运行”** 即可正常进入（由于未购买第三方企业代码签名证书，属于预期现象，软件完全安全且本地离线）。

## 🎬 核心功能操作流程

1. **导入素材：**
   * 点击「导入素材」或直接将多个 MP4 / MOV / MKV 视频素材拖入素材列表。
   * 支持多商品工作组（商品组 A / 商品组 B）隔离操作。

2. **混剪编排设置：**
   * **随机拼接：** 指定每次拼接的分镜片段数量与批次数量，支持固定随机种子。
   * **自定义序号：** 支持紧凑序号（如 `264513`）或逗号分隔序号（如 `2,6,4,5,1,3`）精确控制拼接顺序。
   * **主素材强化（Boost）：** 支持固定主镜头并在前后插入配镜。

3. **画幅适配与视觉风格：**
   * 画幅比例：`9:16`（竖屏短视频）、`16:9`（横屏长视频）、`1:1`（方形）、`4:3` 等。
   * 填充策略：智能背景模糊、居中黑边填充、缩放裁剪。
   * 滤镜与特效：支持水平翻转防重、色彩饱和度/对比度微调。

4. **蒙版、贴纸与音频：**
   * **蒙版图层：** 导入画中画或透明蒙版视频，调整混合模式、位置与缩放。
   * **贴纸轨道：** 支持多图层贴纸叠加与随机洗牌。
   * **BGM 库：** 添加背景音乐，支持自动循环、音量增益与淡入淡出。

5. **字幕实验室（可选）：**
   * **字幕擦除：** 手动框选或通过本地 OCR 自动定位原视频硬字幕并进行模糊去除。
   * **离线识别：** 借助本地 Whisper 引擎离线转写语音生成 SRT/ASS 字幕。
   * **字幕烧录：** 一键将外部字幕以硬字幕形式烧录进成片。

6. **渲染导出与队列管理：**
   * 设置输出目录（默认在源素材目录下的 `分镜输出` 文件夹中，自动追加编号防覆盖）。
   * 点击「入队渲染」，在底部「渲染队列」中实时查看进度百分比与日志。
   * 支持多任务并发、暂停/恢复、单任务取消。
